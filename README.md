
# Gomoku

A simple Five in a Row (Gomoku) game played on a 19×19 grid.

## Features

- 19×19 game board
- Local two-player gameplay
- Black and white stones
- Win detection for five or more stones in a row
- Highlights the winning stones
- Restart the game at any time

## How to Play

1. Black goes first.
2. Players take turns placing one stone on the board.
3. The first player to get five or more stones in a row wins.
4. Stones can connect horizontally, vertically, or diagonally.

## Run Locally

Download all files:

On first launch, double click this exe file "Five in a Row-Setup-1.0.0"
Afterwards launch this exe "Five in a Row-1.0.0-Portable"

No installation or internet connection is required for local gameplay.

## Network Multiplayer

The game currently supports local two-player gameplay on the same device.

It can be extended for network multiplayer by setting up a server to connect players and synchronize game moves. A server could be built using Node.js and WebSockets.
